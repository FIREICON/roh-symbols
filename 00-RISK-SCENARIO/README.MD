# 00 · Risk scenario / Escenari de risc

Símbols que denoten el que l'escenari presenta: escenaris de risc, situacions
concretes, riscos operatius, riscos de prevenció de riscos laborals i elements
físics del lloc. No porten codi documental: el seu referent no és un document.

Les mesures que el servei estableix davant d'aquests riscos —zonificació,
protecció respiratòria, equip de rescat— no són aquí: són a `04-safety/`.
